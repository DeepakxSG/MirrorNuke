# MirrorNuke 2.0.2 — Local preview zoom and immersive viewer

## New features

- **Pinch-to-zoom preview:** two-finger pinch scales only the video preview inside MirrorNuke. It does not send any zoom command to the remote PC and does not change the remote desktop resolution or scaling.
- **Local preview pan:** while two fingers are down, their movement pans the enlarged local preview. The preview is clamped so it cannot be dragged completely off-screen.
- **Correct remote input mapping:** mouse/touch coordinates are inverse-transformed through the local zoom matrix, so remote clicks target the same source location that is visible under the pointer.
- **Gesture separation:** two-finger gestures are reserved for local zoom/pan. If a one-finger remote press was active when the second finger arrived, MirrorNuke releases it to avoid a stuck remote mouse button. One-finger remote click/drag remains available.
- **Zoom reset:** toolbar button, double-tap, or `Ctrl+0` resets local preview zoom.
- **Immersive viewer:** the Full Screen button hides the MirrorNuke toolbar, connection metrics, and video diagnostic HUD. On Windows, the app window becomes borderless and fills the current monitor. On Android, system bars are hidden.
- **Exit controls:** press `Esc` or `F11` on Windows, use the temporary exit icon revealed by moving/tapping, or use the Android back/navigation flow after revealing the exit icon.

## Technical notes

- Added Win32 window-style/monitor APIs in `WinInput` to save and restore the original Windows window style and geometry.
- Added `vector_math` as an explicit dependency for preview-only transform matrices.
- Version incremented to `2.0.2+3`.
